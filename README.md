#  NexAdmin - Dashboard Administrativo

Projeto que criei para praticar HTML, CSS e JavaScript puro, focado em criar um dashboard administrativo responsivo.

> Esse projeto faz parte dos meus estudos de Front-end.

### 🔗 Ver o projeto no ar:
**https://nex-admin-mu.vercel.app**

O que aprendi
-  Estruturação de layout com CSS Grid e Flexbox
-  Responsividade (mobile first)
-  Organização de pastas e componentes
-  Deploy com Git + Vercel (integração contínua)
-  Versionamento com Git

### Tecnologias usadas
- HTML5
- CSS3
- JavaScript (Vanilla)
- Vercel para deploy
